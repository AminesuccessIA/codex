## Post 1 — Power BI

Avant de créer un tableau de bord Power BI, trois décisions sont à prendre :

• Quel indicateur doit éclairer quelle décision ?
• Quelle source permet de vérifier le calcul ?
• Qui peut consulter quelles données ?

Ce cadrage prépare le modèle, les droits d’accès et la recette. Il aide aussi à choisir les licences et le mode de diffusion avant le déploiement.

## Post 2 — Copilot

Déployer Microsoft 365 Copilot commence aussi par une question d’accès : quels documents chaque utilisateur peut-il consulter ?

Avant un pilote, il faut examiner les permissions, les espaces partagés et les usages retenus. Puis définir comment les équipes seront accompagnées et comment les réponses seront vérifiées.

## Post 3 — Azure

Une migration Azure se prépare application par application.

Avant la bascule, il faut identifier les dépendances réseau, les identités, les données et les interfaces. Le plan doit aussi prévoir les tests, la restauration et le passage en exploitation.

Ces points permettent de définir une première vague de migration et ses critères de validation.
